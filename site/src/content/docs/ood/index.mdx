## 객체 지향 설계 문제를 푸는 순서

1. **제약 조건과 가정을 명확히 합니다.** 각 해설의 첫 절이 바로 면접관에게 던질 질문 목록입니다.
2. **핵심 객체(명사)와 행동(동사)을 찾습니다.** 예를 들어 주차장 문제라면 차량, 주차 칸, 층, 주차장이 객체이고, 주차하기·자리 비우기가 행동입니다.
3. **관계와 책임을 나눕니다.** 상속(추상 클래스)과 조합(composition) 중 무엇이 맞는지, 어떤 클래스가 상태를 가지는지 정합니다.
4. **확장 지점을 이야기합니다.** 새 차량 종류, 새 카드 게임처럼 요구 사항이 바뀔 때 어디를 고치면 되는지 설명합니다.
