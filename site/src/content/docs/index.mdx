## 면접까지 얼마나 남았나요?

모든 것을 알아야 하는 것은 아닙니다. 원문의 [학습 가이드](/guide/)는 **넓게 시작해서 몇몇 영역은 깊게** 파고들라고 권합니다. 남은 기간에 맞는 플랜을 고르면 무엇을 어떤 순서로 공부할지 체크리스트로 안내합니다. 진행 상황은 이 브라우저에 저장됩니다.

## 학습 가이드 한눈에 보기

기간이 길수록 같은 범위를 더 깊게 보고, 더 많은 문제를 풀어 봅니다. 각 항목을 누르면 해당 자료로 이동합니다.

## 무엇을 배우나요?

시스템 설계 주제를 요청이 흐르는 순서대로 묶었습니다. 각 주제는 장단점을 함께 정리합니다. **모든 것은 트레이드오프입니다.**

<TopicGrid />

## 해설이 있는 시스템 설계 문제

먼저 직접 설계해 보고 해설과 비교하세요. 해설마다 토론 내용, 코드, 다이어그램이 있습니다.
